# パーツ組み換え設計 (Part Swap Design)

パーツの内部を変更・交換しても、呼び出し元への影響を小さくするための設計の考え方です。呼び出し元は、呼び出し先の内部構造ではなく、外部との入出力の契約に依存します。

## 向いているプロジェクト

機能の一部を継続的に改善するアプリケーションや、処理方式・外部サービスとの接続処理を差し替えるシステムに向いています。一方、機能間の依存関係を切り分けにくい構造には向かない場合があります。

- [適用の判断](docs/applicability.md) — 向いているケース、向いていないケース、判断基準
