# パーツ組み換え設計 (Part Swap Design)

パーツを後から取り替えやすくするための設計の考え方です。

呼び出し元が、呼び出し先の中身を知らなくても使えるようにします。これにより、一部を作り替えるときに、ほかの部分まで修正する手間を減らします。

例えば、ある処理が一つの機能からしか呼ばれないなら、その処理の内部をまとめて取り替えられます。入力と出力の形が同じなら、結果が変わっても、呼び出し方は変えずに済みます。

特定のプログラミング言語や実装方法は決めません。

## 向いているプロジェクト

- 長く開発・保守し、機能の一部を作り替えるプロジェクト
- 計算方法や処理の仕組みを差し替えるプロジェクト

一度しか使わない小さなプログラムなど、分割する手間が見合わない場合もあります。
